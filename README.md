# 💱 P2P iChange.money – p2p-manager

## 🇬🇧 English

**p2p-manager** is a SAAS toolkit designed for P2P traders on the **Bybit** platform.  
It helps you automate ad management, monitor your portfolio, and analyze trading activity.

🔗 Live demo: [https://p2p.ichange.money](https://p2p.ichange.money)  
🌐 GitHub landing page: [https://olegvic.github.io/p2p-manager](https://olegvic.github.io/p2p-manager)

---

### 🚀 Features

- 📊 Live portfolio tracking via Bybit API  
- 🛎 Event-based automation (order created, paid, etc.)  
- ⏰ Time-based automation (auto-enable/disable ads)  
- 📋 View, filter, and edit P2P ads  
- 📈 Custom indicators: BTC dominance, volume, etc.  
- 🔧 Flexible rule system  
- 🧠 Table-like user interface
